# Benchmarks

All numbers below are generated by `scripts/make_tables.py` from the files in `results/`.

## Decode speed

`bench/bench_api.py`, greedy, thinking off, 512-token replies, 3 repetitions, median.
Whole = completion tokens / whole-request wall time (includes prefill and HTTP). Server decode = TabbyAPI's own
generation rate. Acceptance = accepted / (accepted + rejected) draft tokens over the 3 runs.

|---|---|---|---|---|
| RTX 3090 | code | 168.5 | 174.95 | 78% |
| RTX 3090 | math | 152.8 | 158.33 | 70% |
| RTX 3090 | prose | 67.3 | 67.9 | 21% |
| RX 7900 XTX | code | 149.7 | 158.36 | 76% |
| RX 7900 XTX | math | 121.3 | 128.2 | 59% |
| RX 7900 XTX | prose | 64.5 | 65.67 | 23% |
